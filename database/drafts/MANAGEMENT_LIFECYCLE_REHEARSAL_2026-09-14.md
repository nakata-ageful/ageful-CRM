# 管理終了・再開のローカル検証（2026-09-14）

本番未適用。新経路のフラグは未設定のまま。本番SQL、Auth、権限、デプロイは変更していない。

## 実装

- 発電所詳細へ「管理の終了・再開」を接続。保守だけ／すべての取引を分離。
- 終了日は管理する最終日（翌日停止）、再開日は当日から有効。全取引の再開で別途終了した保守を自動再開しない。
- 保存済み予定は全件を確認し、残す／予定額変更／取りやめを明示。発行・入金・振替不能の実績を自動変更しない。
- RPCで行ロック、版確認、同一操作再送、変更履歴と予定変更を原子化。途中失敗時は全体をロールバック。
- 管理イベントは追記専用。契約金額や元の保守開始日は上書きせず、再開日を別履歴に保持。
- 費目別集計・金額確認CSVと将来候補診断に終了境界を反映。保守終了でも土地代などは残る。返金・日割り・残作業アラートは自動化しない。
- runtime snapshot v2、既知19テーブルのバックアップ。新しい管理SQLは manual plan 系の後、runtime SQLの前に読み込む。既適用DBへのアップグレードSQLではなく、新規隔離検証用のドラフト。
