## 1. 画面構成

左サイドバーから各画面に移動できます。

### 新アプリの「管理設定」「変更履歴」

発電所詳細の「管理設定」では、今日時点の継続・終了状態を最初に表示します。必要な操作のボタン（「終了・再開を記録する」「請求予定を追加する」「振替予定を追加する」「請求先・方法・予定額を変更する」）から入力画面を開きます。画面を開いただけでは保存しません。既存の確認・保存手順はそのままで、保存中は閉じる操作を止め、保存失敗時は入力を残します。

「変更履歴」は折り畳みなしの一覧です。「所有者変更」「請求の変更」「終了・再開」で絞り込めます。「詳細を見る」で変更前/変更後を比較し、「保存された全項目を表示」で変更していない項目も確認できます。所有者変更日・終了/再開の適用日と、実際の記録日時は別に表示します。履歴は参照専用で、請求額を再計算・上書きしません。

### 新アプリの顧客選択

「新しい所有者」「請求先」「顧客を選択」の欄では、名前・会社名・ふりがなの一部を入力して候補を絞れます。会社名と顧客IDを確認して候補をクリックしてください。候補は全件スクロール表示し、同姓同名の顧客もIDで区別できます。

検索文字を入力するだけでは選択中の顧客は変わりません。候補のクリック、または上下キーで候補を指定してEnterを押すと切り替わります。日本語入力の確定Enterでは選択しません。「解除」は選択を空欄に戻します。最後に元の保存・確認ボタンで確定するまで、DBには反映しません。

| メニュー | 内容 |
|----------|------|
| ダッシュボード | KPI・アラート・予定の一覧 |
| 見込み管理 | 契約前の案件パイプライン |
| 案件 | 全案件の一覧・詳細 |
| 顧客 | 顧客情報の一覧・詳細 |
| 保守対応 | 保守依頼の対応記録 |
| 請求 | 請求・入金の管理 |
| CSVインポート | CSVファイルからの一括取込 |

## 2. ダッシュボード

ログイン後に最初に表示される画面です。

### KPIカード（画面上部）

| カード | 表示内容 |
|--------|---------|
| 顧客数 | 登録されている顧客の総数 |
| 案件数 | 登録されている案件の総数 |
| 対応中の保守 | ステータスが「対応中」の保守対応件数 |
| 未入金アラート | 請求済みで未入金の件数と合計金額 |

各カードのリンクをクリックすると、該当の一覧画面に遷移します。

### 対応中の保守（左テーブル）

現在対応中の保守案件を最大8件表示します。

- **表示列**: 発電所名、顧客名、問合日、状況、状態
- 行をクリックすると保守対応の詳細画面を開きます

### 未入金アラート（右テーブル）

請求済みで入金が確認されていない案件を表示します。

- **表示列**: 案件名、顧客名、請求金額、入金予定日、状態
- 入金予定日を過ぎている場合、赤字で「超過」と表示されます
- 行をクリックすると請求詳細画面を開きます

### 請求予定（下部テーブル）

請求予定日が設定されているが、まだ請求していない案件を一覧表示します。

- **表示列**: 案件名、顧客名、請求予定日、請求方法、請求金額（税込）
- 請求予定日を過ぎている場合、赤字で「超過」と表示されます

## 3. 顧客管理

### 顧客一覧

全顧客を一覧表示します。

- **検索**: 顧客名・会社名・電話番号・メールで検索できます
- **表示列**: 顧客名、会社名、種別（法人/個人）、電話番号、メール、案件数
- 行をクリックすると顧客詳細画面を開きます

### 顧客の新規作成

1. 「＋ 新規顧客」ボタンをクリック
2. 以下の情報を入力:
   - **顧客名**（必須）
   - 会社名（入力すると自動的に「法人」になります）
   - 電話番号
   - メールアドレス
   - 郵便番号
   - 住所
3. 「保存」をクリック

### 顧客詳細画面

顧客の情報と、紐づく案件・添付ファイルを確認できます。

- **顧客情報**: 「編集」ボタンで情報を更新できます
- **案件一覧**: この顧客に紐づく案件の一覧。「＋ 案件を追加」で新規案件を作成できます
- **添付ファイル**: PDF・画像などのファイルを添付できます（詳細は[10. 添付ファイル](#10-添付ファイル)参照）

### 顧客の削除

顧客編集モーダルの下部にある「削除」ボタンから削除できます。
**注意**: 顧客を削除すると、紐づく案件・契約・請求データもすべて削除されます。

## 4. 案件管理

### 案件一覧

全案件を一覧表示します。

- **検索**: 案件名・案件番号・顧客名・設置住所・都道府県で検索できます
- **表示列**: 案件名、顧客名、都道府県、FIT期間、委託先、引渡日、監視システム

### 案件の新規作成

1. 「＋ 新規案件登録」ボタンをクリック
2. 顧客を選択（既存顧客 or 新規作成）
3. 案件情報を入力:
   - **案件名**（必須）
   - 案件番号、キー番号、都道府県、設置住所
   - 系統ID、系統認定日、FIT期間、需給開始日
   - お客さま番号、発電地点特定番号
   - 引渡日、販売会社、紹介者、販売価格
   - 監視システム、監視ID
   - 備考
4. 「保存」をクリック

### 案件詳細画面

案件詳細は4つのタブに分かれています。

#### 基本情報タブ

案件の基本情報をすべて表示します。「編集」ボタンで情報を更新できます。

表示される情報:
- 所在地情報（郵便番号、都道府県、住所、座標）
- パネル情報（kW、枚数、メーカー、型式）
- PCS情報（kW、台数、メーカー、型式）
- FIT・系統情報（系統ID、認定日、FIT期間、需給開始日）
- 監視情報（システム、ID、ユーザー名、PW、4G対応）
- その他（カギNo、自治会、旧所有者、販売会社、紹介者、各種日付、価格）

**契約情報**もこのタブに表示されます。契約がない場合は「＋ 契約情報を追加」ボタンが表示されます。

#### 保守対応タブ

この案件に紐づく保守対応の一覧を表示します。詳細は[5. 保守対応](#5-保守対応)を参照。

#### 定期保守タブ

この案件の定期保守記録を表示します。詳細は[6. 定期保守](#6-定期保守)を参照。

#### 請求タブ

この案件の契約情報と年度別の請求記録を表示します。詳細は[7. 請求管理](#7-請求管理)を参照。

## 5. 保守対応

発電所の故障・異常などへの対応を記録します。

### 保守対応一覧

- **検索**: 発電所名・顧客名・対象箇所・状況・管理番号で検索できます
- **フィルタ**: 「対応中」「完了」「すべて」のタブで絞り込めます（件数表示あり）
- **表示列**: 管理番号、発電所名、顧客名、問合日、発生日、対象箇所、状態

### 保守対応の新規作成

案件詳細画面の「保守対応」タブから追加できます。

1. 「＋ 保守対応を追加」をクリック
2. 以下の情報を入力:
   - 問合日
   - 発生日
   - 対象箇所
   - 状況（テキスト）
   - 対応（テキスト）
   - 報告（テキスト）
3. 「保存」をクリック

管理番号（例: 26001）は自動で採番されます。ステータスは「対応中」で作成されます。

### 保守対応の詳細・編集

保守対応の詳細画面では以下の操作ができます:

- **編集**: 「編集」ボタンで全項目を更新できます
- **完了にする**: 「完了にする」ボタンでステータスを「完了」に変更します
- **削除**: 案件詳細の保守対応タブから削除できます

### ステータスの流れ

```
対応中 → 完了
```

## 6. 定期保守

点検・除草・巡回などの定期的な保守作業を記録します。

### 定期保守の追加

案件詳細画面の「定期保守」タブから追加できます。

1. 「＋ 定期保守を追加」をクリック
2. 以下の情報を入力:
   - **記録日**（必須）
   - 作業種別: 点検 / 除草 / 巡回 / その他
   - 内容（テキスト）
3. 「保存」をクリック

### 定期保守の操作

- **追加**: 上記の通り
- **削除**: 各記録の削除ボタンで削除
- **編集**: 編集機能はありません。修正する場合は削除してから再度追加してください

## 7. 請求管理

### 新アプリ：請求タブの一覧

新アプリでは発電所をまたいで「請求1回につき1行」で表示します。

- **未入金（赤）**：請求日・入金予定日・確定金額を日付順に表示。「入金日を記録」でその回の入力画面を開き、保存します。発電所名を押すと明細と履歴を確認できます。
- **今月・来月・再来月の請求予定（青）**：保存済み予定と契約からの候補を同じ一覧に日付順で表示。保存済み回の「発行」から明細・請求日・入金予定日を入力できます。「参考額」「請求先未確定」「未保存」の候補は「予定を確認」で詳細を開き、期間・請求先・金額を確認してから登録します。予定を保存しただけでは一覧から消えません。
- **口座振替（紫・折り畳み）**：常時の振替発電所、確認日を過ぎた結果確認候補、保存済み振替予定を確認。契約の今月参考額と保存済み各回の金額は別扱いです。銀行への振替手配は行いません。
- **入金済（緑・折り畳み）**：入金日の新しい順で確認。その他の予定・記録・請求設定の要確認項目も、件数付きの欄を開いて確認します。
- **古い未入金**：今年度・昨年度より前の未入金も警告として初期表示に残します。金額不明分を現在の契約から推測して埋めたり、合計に含めたりしません。

各回に保存した請求先と確定金額を表示するため、所有者変更後も過去の請求先・金額は変わりません。「請求詳細」の過去の記録は保守期間ごとにまとめ、同じ期間の2回は同じ枠に表示します。

以下の年次記録の説明は旧方式です。新アプリの請求保存は回別の記録を使用します。

### 請求の仕組み

請求データは以下の3層構造になっています:

```
案件 → 契約 → 年次記録（年度ごとの請求・入金）
```

請求機能を使うには、案件ごとに**契約情報**を作成し、その契約に対して**年次記録**を追加する必要があります。

### 契約情報の作成・編集

案件詳細の「請求」タブ、または「基本情報」タブから操作します。

契約の主な項目:

| 項目 | 説明 |
|------|------|
| 請求方法 | 「請求書」または「口座振替」 |
| 請求予定日 | 例: 12月1日 |
| 請求金額（税別/税込） | 年間の請求金額 |
| 年間保守料（税別/税込） | 保守契約の金額 |
| 土地賃料 | 月額の土地代 |
| 保険料 | 年間保険料 |
| その他 | その他費用 |
| 振替手数料 | 口座振替の場合の手数料 |
| 各種契約日 | 売買契約日、設備契約日、土地契約日、保守契約日 |
| 販売経路 | 販売店→ネオシス、ネオシス→紹介者、契約者名 |
| 保守委託 | 委託先、委託料、委託開始日 |
| 保守プラン | 点検・除草・駆付（各: なし / 年1回 / 無制限） |

### 年次記録の作成・編集

案件詳細の「請求」タブで年度ごとの請求・入金を管理します。

年次記録の主な項目:

| 項目 | 説明 |
|------|------|
| 年 | 対象年度（例: 2026） |
| 請求予定日 | 請求を送る予定の日付 |
| 請求日 | 実際に請求した日付 |
| 入金予定日 | 入金を見込む日付 |
| 入金日 | 実際に入金があった日付 |
| 請求明細 | 品目名と金額のリスト |
| ステータス | 未入金 / 請求済 / 入金済 |

### 請求一覧画面

請求一覧は自動的に以下の4セクションに分類されます:

#### 未入金アラート（赤枠）

請求済みで入金が確認されていない案件を表示します。

- 各行に入金日の入力欄があります
- 入金日を入力して「入金日を保存して消し込む」ボタンで一括保存できます
- 口座振替の場合は「振替」バッジが表示されます

#### 請求予定（青枠）

請求予定日が設定されているが、まだ請求していない案件です。

- 請求方法と保守プランが表示されます
- 予定日を過ぎている場合は「超過」と赤く表示されます

#### 口座振替（紫枠）

口座振替で振替待ちの案件を表示します。

#### 入金済（緑枠・折りたたみ）

入金確認済みの案件です。デフォルトでは折りたたまれています。

### 請求詳細画面

請求一覧で案件をクリックすると、詳細画面が開きます。

- **契約情報**: 請求方法、保守プランなどを確認・編集
- **今年度の請求**: 請求日・入金日・明細を入力。ステータスは日付の入力状況から自動判定されます
- **年度別請求履歴**: 過去年度の請求記録を確認・編集
- **保守情報**: 委託先・委託料などの保守関連情報
- **保守対応/定期保守**: この案件の保守履歴

### 新アプリ：日常の請求・振替と期間別履歴

「請求情報」は請求方法・予定日の基本設定と請求対象項目を管理する場所です。毎回の作業は「請求詳細」で行います。

- 保存記録がなくても、契約から計算した参考額・予定日・対象期間が表示されます。「未登録」の候補は実際の請求・入金履歴ではありません。
- 「予定を登録」または「＋ 請求・振替予定を追加」で、対象の保守期間・第何回か・請求先・日付・予定額・確認内容を確認し、1回分の予定を保存します。対象の回・期間・日付を変更した場合は予定額を再入力します。既存記録を上書きしません。
- 口座振替は「振替結果を記録」から入金日・実額・明細を記録します。未登録なら、まず予定の確認・保存に進み、その後に結果を入力します。銀行への手配は行いません。
- 請求書は「請求内容を入力して発行」で実際の請求日・入金予定日・明細を保存し、「入金日を記録」で入金を確認します。請求書の自動生成・送信は行いません。
- 履歴は保守期間ごとにまとめます。同じ期間に2回あれば第1回・第2回が同じ枠内に並び、それぞれの金額・請求先・日付を表示します。前払いの請求日が前年でも、対象の保守期間でまとめます。予定と実績は状態・金額の表示で区別します。
- 各回を選ぶと左側に詳細が表示され、「この記録を訂正」で訂正前の内容と理由を残して修正できます。
- 明示的に保存された期間が優先です。未保存の期間は保守開始日からの「参考・未確認」表示で、自動保存しません。保守開始日が未設定の場合は参考金額の確認はできますが、「保守情報」で開始日を設定するまで通常の予定追加はできません。回の対応が不明な既存記録や取りやめた回を自動で作り直すこともありません。

### 新アプリ：保守期間の確認・修正

#### 毎年1月〜12月の保守・前年12月1日請求に切り替える場合

「請求書・年1回」の発電所で、発電所詳細の「請求情報」→「今後の保守期間・請求の繰り返し」→「繰り返し設定を変更」を使います。発電所ごとに一度設定します。ほかの発電所には反映されません。

1. 8月〜年末などの移行期間は、下記の「保守期間の確認・修正」で先に保存します。短い期間の金額は自動で日割り・月割りしません。
2. 繰り返し方法で「1月〜12月の保守／前年12月1日に翌年分を請求」を選び、「何年分の保守期間から適用するか」を入力します。2027年なら、2027年1月1日〜12月31日分を2026年12月1日に請求する候補になります。
3. 3年分の表示と確認内容・備考を確認して、「設定内容を確認」→「確認した繰り返し設定を保存」を押します。期間の重複や切替後の保存済み記録との不一致があれば、修正が必要な旨を表示して保存を止めます。
4. 「請求詳細」の「予定を登録」で請求先と金額を確認し、予定を保存します。次の年からも、1月〜12月と前年12月1日が候補に入ります。毎年の期間修正は不要です。実際の請求日・入金日は従来どおり記録します。

設定が適用されるのは未登録の予定候補です。当初の保守開始日、過去の記録、保存済みの予定・金額・請求先・請求日・入金日は変更しません。すでに保存している予定を変える場合は、その記録を個別に確認してください。繰り返し設定は「変更履歴」の「請求の変更」に残ります。請求書の自動生成・送信や全発電所の一括切替は行いません。

初年度が翌年末まで続く場合は、その長い期間を残し、翌々年分から繰り返し設定を開始します。例：2026年10月27日〜2027年12月31日が請求済みなら、適用開始年を2028にして2028年1月〜12月分を2027年12月1日に請求します。保存済み期間・請求済み状態と設定が一致した場合だけ、重なる古い周年候補を除きます。曖昧な期間や未発行の記録は自動で請求済みとせず、「未保存・要確認の請求予定」に残します。

「要確認」「日付要確認」「表示期間より前の予定」は請求画面とダッシュボードで初期表示します。前年に翌年分を発行した場合も「未入金」に残り、入金を記録して初めて「入金済」に移ります。3か月より先の予定は「それ以降の予定」、日付なしの保存予定は「日付要確認」で確認してください。アラートは実績を推測して確定する機能ではありません。

新しい請求機能では、対象の保守期間と請求予定日・請求日・入金日を別に管理します。通常の保守期間は、保守開始日の月日から翌年の前日までの1年間です（例：2026年7月14日〜2027年7月13日）。次の期間の分を前年12月に請求する場合も、過去の請求記録は上書きしません。

発電所の「請求詳細」→「保守期間の確認・修正」→「保守期間ごとの保存記録を確認」を開きます。過去の期間も「この期間の保存記録を修正」から編集できます。

1. 「保守開始日から1年間を入力」で通常の期間を入力するか、開始日・終了日を個別に指定します。
2. 修正理由を入力し、「修正内容を確認」で対象件数と修正後の期間を確認します。
3. 「確認した保守期間だけを保存」で保存します。

同じ開始年に属する保存済みの回をまとめて修正します。請求先・金額・請求予定日・請求日・入金日は変わらず、期間の変更履歴を残します。ほかの保守期間との重複は拒否されます。保存された開始年自体の付け替えはこの操作では行いません。明示的に保存済みの例外期間は、画面を開くだけでは変更されません。期間未保存の参考表示も、自動で確定保存しません。

### 旧方式：ステータスの自動判定

```
入金日あり     → 入金済
請求日あり     → 請求済
それ以外       → 未入金
```

### ダッシュボードにアラートを表示するために必要な項目

| アラート | 必要な設定 |
|---------|-----------|
| 未入金アラート | ① 契約を作成 ② 年次記録を作成 ③ 請求日を入力（入金日は空のまま） |
| 請求予定 | ① 契約を作成 ② 年次記録を作成 ③ 請求予定日を入力（請求日は空のまま） |
| 対応中の保守 | 保守対応を「対応中」ステータスで追加 |

## 8. 見込み管理

契約前の案件（見込み案件）を管理します。ローン申込から契約完了までの進捗をタスクベースで追跡できます。

### 見込み一覧

- **フィルタ**: 申込ステータスと契約ステータスの2軸で絞り込み
- カード形式で表示されます

### 見込み案件の新規作成

1. 「＋ 案件を追加」をクリック
2. 以下の情報を入力:
   - **顧客名**（必須）
   - **物件名**（必須）
   - ローン会社（アプラス / ジャックス / 空欄）
   - 物件所在地、設備費、土地費、融資額、kW数、紹介元、商談開始日
3. 「保存」をクリック

### 見込み詳細画面

#### KPIカード

設備費・土地費・合計・融資額を表示します。

#### 基本情報

日付・住所フィールドを直接編集できます（自動保存）:

- 商談開始日
- 申込提出日
- 審査結果日
- 売買契約日
- 土地契約日
- 引渡し予定日
- 物件所在地

#### タスクパネル（申込 / 契約）

ローン会社に応じたチェックリストが表示されます。

**申込タスク（例: アプラス）:**
- ローン申込書
  - └ 金利変動確認欄
- 確認書（アンケート）
- 確認票（保険）
- 収入証明書

**契約タスク:**
- 売買契約書
  - └ 顧客へ郵送
  - └ 代理店へ郵送
- 土地契約書
  - └ 顧客へ郵送
  - └ 代理店へ郵送
- 住民票
- 印鑑証明書
- 契約チェック

各タスクのチェックボックスをクリックすると自動保存されます。メモ欄も自動保存です。

#### ステータス変更

申込・契約それぞれのパネルで、ステータスボタンをクリックして変更します。

**申込ステータス:**
```
未 → 提出済 → 通過 / 不通 / 不可
```

**契約ステータス:**
```
未 → 完了 / 不可
```

### 顧客管理への登録（コンバージョン）

契約ステータスが「完了」になると、「顧客管理へ登録 →」ボタンが表示されます。

1. ボタンをクリック
2. 確認ダイアログで内容を確認
3. 「登録する」をクリック

見込み案件の情報をもとに、顧客・案件が自動作成されます。登録後は「✓ 顧客管理済」と表示されます。

## 9. CSVインポート

CSVファイルから案件データを一括で取り込みます。

### 対応フォーマット

| フォーマット | 説明 |
|-------------|------|
| テンプレート形式 | アプリからダウンロードしたテンプレートに合わせた形式 |
| 既存データ形式 | 2行ヘッダーの既存管理データ |
| 全体シート形式 | エイジフル低圧一覧の全体シート（契約・請求情報含む） |

フォーマットは自動判定されます。

### インポート手順

1. **テンプレートのダウンロード**（任意）: 「CSVテンプレートをダウンロード」ボタンをクリック
2. **CSVファイルの選択**: ファイルをドラッグ&ドロップ、またはクリックして選択
3. **プレビュー確認**: 取込対象のデータが一覧で表示されます。内容を確認してください
4. **インポート実行**: 「○件をインポート」ボタンをクリック
5. **結果確認**: 成功件数・失敗件数が表示されます。失敗した行はエラー詳細を確認してください

### 文字コード

UTF-8（BOM付き/なし）とShift-JISに対応しています。自動判定されます。

### 顧客の名寄せ

同じ顧客名の案件は、自動的に同一顧客として紐づけられます。1人の顧客に複数の案件が登録されます。

### インポート前のデータクリア

既存データを全て消してから再インポートする場合は、SupabaseのSQLエディタで以下を実行してください:

```sql
TRUNCATE customers CASCADE;
```

これにより顧客・案件・契約・請求・保守データが全て削除されます。

## 10. 添付ファイル

顧客に対してファイルを添付できます。

### 対応ファイル形式

PDF、PNG、JPG、JPEG、GIF、WEBP、DOC、DOCX、XLS、XLSX

### ファイルの追加

1. 顧客詳細画面の「添付ファイル」セクションで「＋ ファイルを追加」をクリック
2. ファイルをドラッグ&ドロップ、またはクリックして選択
3. 説明（任意）を入力
4. 「アップロード」をクリック

### ファイルの操作

- **開く**: 「開く」ボタンでファイルを新しいタブで表示
- **削除**: 削除ボタン（🗑）をクリック → 確認ダイアログで「削除」
