## Runtime permission correction found by this rehearsal

The private write helpers must run with the runtime function owner's privileges because the ledger/audit tables intentionally have no authenticated write grants. Authenticated users receive owner-scoped `SELECT` only on `billing_operations` and `billing_unit_events`; writes remain available only through `billing_runtime_write`.
