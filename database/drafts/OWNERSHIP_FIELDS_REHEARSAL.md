# 所有者変更の項目選択（保存前処理）

`src/lib/ownership-field-selection.ts`はD-026を実装した純粋な保存前処理。通常画面／DBへ未接続。

- Contract54項目・Project55項目を明示分類。Record<keyof ...>で型の追加時に分類漏れを検出する。
- 編集対象は指定がなければ保持。変更／空欄化は明示選択のみ。optionalの欠落とnullは区別して保持する。
- 全項目の変更前後と選択結果を値コピー。片方を後から変えても元記録・他方は変わらない。
- 所有者・旧所有者・移転日・ID・登録日は選択では変更不可。これらは後続の移転RPCが認証・確認のうえ更新する。
- 型にないDB追加項目は黙って落とさず停止する。型と実DBの全列一致の実査は別途必要。
- 設備契約日の空欄化では、旧売買契約日への表示フォールバックが残っていれば停止する。実UIは両方をひとつの操作として扱い、確認結果にも反映する必要がある。

`node tests/ownership-field-selection.cjs`と型検査で確認。実績請求は入力対象外で、再計算・変更しない。
